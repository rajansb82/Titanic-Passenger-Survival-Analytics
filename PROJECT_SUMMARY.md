# Project Summary

## Title
**Titanic Passenger Survival Analytics & Predictive Modeling using R**

## Problem Statement
Passenger survival was influenced by multiple demographic and socioeconomic factors. The goal is to build a reproducible analytical system that identifies these relationships and evaluates whether they can be used to predict survival.

## Technical Contribution
This project implements a complete R-based analytics pipeline rather than relying on manual spreadsheet analysis:

**Raw CSV → Data Validation → Cleaning → Feature Engineering → EDA → Statistical Testing → Logistic Regression → Cross-Validation → ROC/AUC → Baseline Comparison**

## Engineering Practices Demonstrated

- modular R scripts
- reproducible random seed
- automated directory creation
- automated package installation
- raw/processed data separation
- saved model objects
- generated CSV result tables
- generated high-resolution plots
- train/test separation
- cross-validation
- model diagnostics
- interpretable odds-ratio reporting

## Portfolio Value

This project demonstrates practical skills relevant to:

- Data Analyst
- Junior Data Scientist
- Machine Learning Intern
- Business Intelligence / Analytics roles

It also provides a strong foundation for extending the project into an interactive R Shiny dashboard.
